Configuration à faire une seule fois

Brancher la base partagée

  1. Créer un projet gratuit sur supabase.com.
  2. Dans SQL Editor, coller et exécuter le contenu du fichier schema.sql.
  3. Dans Project Settings → API, copier l'URL et la clé anon public.
  4. Les coller en haut du fichier index.html, puis pousser sur GitHub :
var SUPABASE_URL  = "https://xxxxxxxx.supabase.co";
var SUPABASE_ANON = "eyJhbGciOi...";

En attendant, la page fonctionne en local : les saisies restent dans ce navigateur.
